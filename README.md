# AIStudy

AIStudy is a Flask-based study platform where students will be able to upload study material, generate summaries, ask questions, take quizzes and track their learning progress.

## Current Features

- Flask application setup
- Responsive home page
- Jinja template inheritance
- MySQL database connection
- Environment-variable configuration

## Planned Features

- User registration and login
- Document upload and management
- Text extraction from study material
- Study-note summaries
- Question and answer system
- Quiz generation
- Score and progress tracking

## Technologies

- Python
- Flask
- HTML
- CSS
- Jinja2
- MySQL
- MySQL Connector/Python
